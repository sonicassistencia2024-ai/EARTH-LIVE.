# EARTH LIVE

Visualização da Terra em WebGL preparada para GitHub Pages.

## Como publicar

1. Crie um repositório chamado `EARTH-LIVE` no GitHub.
2. Envie todos os arquivos mantendo as pastas.
3. Vá em **Settings → Pages**.
4. Em **Build and deployment**, escolha **Deploy from a branch**.
5. Selecione `main` e `/ (root)`.
6. Salve.
7. O endereço será parecido com:
   `https://SEU-USUARIO.github.io/EARTH-LIVE/`

## Dados externos

- Terra: NASA Blue Marble
- Órbita ISS: CelesTrak
- Propagação orbital: satellite.js
